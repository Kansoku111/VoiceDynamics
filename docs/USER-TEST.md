# VoiceDynamics 0.2.3 実機確認チェックリスト（Studio One 6 / REAPER）

導入先：`C:\Program Files\Common Files\VST3\VoiceDynamics.vst3`（メーカー名は「Kansoku111」）。
開発側は自動試験・validator・pluginvalまで確認済みで、**以下はまだ誰も確認していません**。結果（○×とメモ）を返してください。

## A. 読み込み（Studio One 6）
1. 新しい曲を作り、声のトラックにインサートで VoiceDynamics を挿す。一覧に出ない場合は再スキャン／再起動。
2. 画面が1つ開く（AuditionのDynamicsに近い暗い画面。ノブを上下または左右ドラッグで回せる、ダブルクリックで初期値、青い数値をクリックして入力できる）。崩れ・文字切れがないか。閉じて開き直しても同じ。
3. プラグインを外す・複数挿す・バイパスして落ちないか。

## B. 再生学習（中心）
1. 目標を −23 LUFS、上限 −1 dBTP にする。
2. ［学習開始］を押す。状態が「待機」になる。
3. **トラックを先頭から最後まで再生**する。再生中は音が通常どおり出て、状態が「学習中」と経過時間になる。
4. 最後まで来たら［学習終了］を押す（または「停止で学習を終える」をオンにして停止）。「計算中」→「完了」。補正ゲイン・測定値・予測値・True Peak・最大GRが出る。
5. 警告の確認（任意）：途中から再生して［学習終了］／再生中に巻き戻し／サンプルレート変更 → 画面に警告が出るか。
6. 学習の後で**目標ラウドネスだけを変える** → 約0.5秒後に「計算中」→「完了」になり、再生し直さずに新しい目標に合うか（0.2.0の新機能。リミッターの上限・リリースも同じ）。
7. ゲート・コンプ・レベラーの設定を変える → 「設定が変わりました」のままになり、学習し直しを求めるか。
8. 曲を開き直した後や、プラグインを無効にした後は記録が消えるため、目標を変えると「設定が変わりました」になる（学習し直しが必要）。

## C. 書き出しと測定
1. 学習済みの状態で、曲全体をWAVに書き出す（Studio Oneはリアルタイム/高速どちらでも）。
2. 書き出したWAVを、お使いのLUFSメーター（Youlean、Waves WLM、iZotope等）で測る。
   - Integratedが目標 −23 LUFS の **±0.1〜0.2 LU以内**（メーターごとの差を含む）。
   - True Peakが −1 dBTP以下。
3. 目標を −16 LUFS に変え（学習し直さず、自動の再計算を待つ）、同様に測る。
4. 「目標に届かない」が出る条件（極端に高い目標）で、表示が出るか。

## D. 保存と復元
1. 曲を保存して閉じ、開き直す。結果（完了と数値）が残り、再学習なしで同じ音量で書き出せる。
2. プロジェクトを別のサンプルレートで開いた場合の挙動（警告が出るか）。

## E. 補助：WAV解析
1. 画面にWAVをドロップする（または選ぶ）。同じサンプルレートのWAVで結果が出る。違う場合は断られる。
2. ドロップが届かないホストがあればメモ。

## F. REAPER
1. B〜Dと同じ。特に**書き出し（レンダリング）中に学習できるか**、ドライランで高速に流せるか。
2. 「学習が速く終わる」ときに取りこぼし警告が出ないか。

## G. 試聴
- ゲートの切れ方（語尾が欠けない、息が不自然に消えない）、コンプの効き、レベラー（オンにしたとき）、リミッターの歪み、ゲインが上がったときのノイズ。
- 遅延補正：他トラックとずれないか（報告遅延は約6.7 ms）。
- CPU負荷（Studio Oneの負荷表示）。
